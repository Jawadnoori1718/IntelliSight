# IntelliSight — Backend

The Python **FastAPI** backend. This is IntelliSight's brain and senses:

- **YOLO** — object detection
- **EasyOCR** — text recognition
- **Claude (multimodal)** — scene understanding, explanations, Q&A
- **Memory** — object timeline, search, and relationships
- **WebSockets** — low-latency realtime detection stream to the frontend

> 🚧 Built starting in **Phase 2**. See [`../docs/ROADMAP.md`](../docs/ROADMAP.md).
